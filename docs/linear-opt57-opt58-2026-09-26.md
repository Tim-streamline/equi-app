# OPT-57 / OPT-58 implementation status (26 September 2026)

## OPT-58 implemented

- Library has one horizontally scrolling navigation row: Alles, Opgeslagen, categories. Alles clears saved/category selection; search and category OR matching remain.
- Removed the filter panel and Stalling field from horse creation. The horse edit screen did not expose Stalling.
- Login has an accessible password visibility toggle, hidden by default.
- Related content is titled GERELATEERDE ITEMS for the shared detail component.

## OPT-57 implemented foundation; payment and push integration pending

- Immutable credit transaction ledger and separate grant batches; existing balances become explicitly labelled opening adjustments. Existing unlocks remain.
- Transactional, account-serialized spending in expiry order, nonnegative balances and unique permanent item unlocks.
- Internal verified-payment settlement: idempotent grants, membership cap, six-month purchase expiry, and reversal of unspent credits with spent-credit support flags.
- Configurable monthly grant, cap, purchase validity and bundle catalog in `/admin/credits`. Bundle amounts/prices have intentionally not been invented.
- Credits API and account screen: separate balances, history, expiry notices, Basic cancellation through the paid period and shared buy entry from locked content.
- Plus no longer bypasses library credit prices or appears as a library gate.
- `credits:maintain` expires purchases and ends cancellations at the end of the paid period. It runs hourly through Laravel's existing scheduler. Reads also exclude/record expired credits.
- Active membership credits do not expire merely because a renewal date passes. Actual cancellation/end expires them; changing a date or status does not grant credits.
- Purchase orders snapshot prices/credit quantities and use per-account request keys. A browser return is not proof of payment.

### Outstanding decisions / integration

The repository had no payment provider, checkout or renewal webhook integration. A payment-provider choice was requested (Mollie, Stripe, or defer live payments). `CreditPaymentGateway` is currently bound to `UnconfiguredCreditPayments`, which advertises unavailable checkout and grants nothing. Provider checkout, verified webhook/reconciliation, recurring Basic order creation, provider cancellation, refund/chargeback events, and end-to-end payment/return verification remain to be implemented once selected. OPT-57 must not be marked complete yet.

Expo push reminders require approval: automatic approval review rejected adding scheduled transmission of device tokens, user IDs and credit-expiry details to Expo. No such transmission was added. In-app reminders highlight purchased credits expiring within 30 days, with an urgent state within 7 days. Push deduplication storage is prepared but unused.
