## OPT-102

The current contact questionnaire had no separate opt-in field; its six questions and dynamically calculated counts remain unchanged. The separate therapist submission notification remains enabled.

## OPT-103

Added shared keyboard viewport, scrolling and input components using existing React Native APIs. Screens account for header/safe-area offsets, reveal their own focused input, cap multiline fields to available space, and retain user scrolling. Background screens do not scroll when a modal owns focus. Applied to intake, onboarding, library search, community forms/dialogs, observations, chat and sheets. Weekupdate content and save/cancel actions are in one bounded scroll area.
